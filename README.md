## 你的桌面，不只是一张图片

Foldwalls 是一款原生 macOS 桌面应用，将高画质动态壁纸、音乐桌面、多显示器管理和互动实验集成在一个干净的原生体验中。

- 图片与视频动态壁纸，支持本地素材导入
- 每台显示器独立设置，适配 Apple 芯片与 Intel Mac
- 音乐桌面实时跟随系统播放器，展示封面、歌词与进度
- AgentGuard 在 AI 任务、下载和后台工作继续运行时，以 Foldwalls 壁纸守护本地屏幕
- 系统锁屏、休眠、电池和全屏场景下的智能播放策略
- 宠物、3D 模型、全景与文字动效等互动实验
- 在线内容目录与本地缓存，断网时仍可使用已下载内容
- 内置自动更新，新版本可直接在应用内安装
