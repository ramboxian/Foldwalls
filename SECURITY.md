# Security

Please do not disclose a suspected Foldwalls security issue in a public GitHub issue.

Report security concerns through the contact channel on the [Foldwalls support page](https://foldwalls.app/support). Include the affected app version, macOS version, reproduction steps, and any relevant logs that do not contain personal information.

The maintainers will review the report and provide follow-up through the contact information supplied by the reporter.
